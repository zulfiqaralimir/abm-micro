# ABM Micro

A web book presenting Asad Zaman's agent-based modeling (ABM) microeconomics
course (Ibn Haldun University, Istanbul) — rebuilding the demand curve, market
equilibrium, welfare theorems, rent control, and the minimum wage from small,
hand-computable agent-based models.

Includes a separate **Applications** section (Programming, DSA, LeetCode,
System Design, LLD, Reference) cross-linked from course chapters, and an
interactive **Sandbox** for building your own ABM.

## Stack

Next.js (App Router) + TypeScript + MDX + Tailwind CSS + Framer Motion + Vercel.

## Getting Started

```bash
npm install
npm run dev
```

See [`CLAUDE.md`](./CLAUDE.md) for the full specification and phased build
order. Follow the phases in sequence — do not skip ahead.
